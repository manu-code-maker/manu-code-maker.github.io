## 🚀 Featured Open Source Repositories

### 1. [agentic-qa-mcp-suite](https://github.com/manu-code-maker/agentic-qa-mcp-suite)
*Autonomous Agentic QA & Test Generation Framework powered by MCP, LLM reasoning, Playwright, and self-healing locators.*
- **AI Agent Governance:** Strict `AGENTS.md` constitution forbidding flaky patterns (`no waitForTimeout`, `no XPath`, `strictObject` Zod schemas).
- **Stagehand-Style Action Caching:** Cached resolved locators with 100% confidence for $0 LLM cost and 0ms latency on regressions.
- **Heuristic Self-Healing:** Autonomous fallback via accessibility tree snapshot when selectors break.

### 2. [enterprise-playwright-framework](https://github.com/manu-code-maker/enterprise-playwright-framework)
*Production-grade Playwright & API Hybrid Test Automation Framework.*
- **Advanced POM + COM Architecture:** Reusable components, base page abstractions, and fixture dependency injection (`base.fixture.ts`).
- **Session Reusability (`storageState`):** Pre-authenticated sessions stored in `.auth/user.json` reducing regression runtimes by over 60%.
- **Contract Schema Validation:** Strict Zod contracts catching payload drift and backend breaking changes.
- **CI Sharding Matrix:** 4-shard parallel execution on GitHub Actions with automatic blob report consolidation.

### 3. [jmeter-performance-sla-gate](https://github.com/manu-code-maker/jmeter-performance-sla-gate)
*Automated Non-GUI Apache JMeter Performance Framework with CI/CD SLA Quality Gating.*
- **100% Non-GUI Execution:** Containerized headless runner designed for Linux CI pipelines.
- **Percentile-Driven SLA Gate:** Standalone Python engine enforcing strict p90, p95, p99, and error rate quality gates.
- **Automated Deployment Blocking:** Halts CD release pipelines if latency or error thresholds are violated.
- **JMeter HTML Dashboard Generation:** Automatic archiving of response time distribution and throughput charts.
