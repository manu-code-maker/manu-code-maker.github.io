Agentic QA & Synthetic Data Generator

Framework de ingeniería agéntica que conecta especificaciones funcionales (Jira / Gherkin) y contratos OpenAPI con agentes de código (Claude Code / MCP). Transforma automáticamente requerimientos en suites completas de Playwright con asertos semánticos y genera datasets sintéticos relacionales para pruebas de backend.

  • Generación Automática: Pasa de Historia de Usuario a tests ejecutables en Playwright en segundos.
  • Self-Healing Selector Logic: Sugerencia de selectores alternativos ante cambios de DOM sin romper la suite.
  • Protocolo MCP Integrado: Servidor MCP local para que el agente inspeccione trazas de red y esquemas de base de datos.

agentic-runner.ts 
import { AgenticTestGenerator } from '@qa/agent-mcp';

// 1. Ingresar especificación de Story
const spec = await loadUserStory('US-4021-checkout.md');

// 2. Agente genera matrices BDD + Synthetic Data
const suite = await AgenticTestGenerator.compile({
  userStory: spec,
  targetFramework: 'playwright-ts',
  generateEdgeCases: true,
  fakerLocale: 'es_ES'
});

// 3. Salida validada contra contratos OpenAPI
console.log(`✅ Generated ${suite.tests.length} tests without flakiness`);
